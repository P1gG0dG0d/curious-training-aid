# 0.2.15 锁屏通知显示完整倒计时

## 问题

小米澎湃 OS 4 的锁屏通知有「列表 / 堆叠 / 数量」三种样式，默认是「堆叠」：所有通知收拢到锁屏底部的「更多通知」里，点开才能看到内容。用户只看到「更多通知 + 应用图标」，看不到「休息中 · 卧推 01:30」。

## 结论：这是系统样式，App 不能强制展开

- 「堆叠」是澎湃 OS 4 锁屏通知样式的默认值，属于 SystemUI 行为，第三方 App 没有接口强制把自己的通知从堆叠里展开或置顶。
- 真正的「像系统倒计时那样常驻在锁屏/岛上」对应小米「焦点通知 / 超级岛」，需要企业主体、在架应用、场景预审，个人自用、未上架的包按官方规则无法接入（与 0.2.14 的结论一致）。
- 用户侧解决：设置 → 锁屏 → 锁屏通知样式 → 选「列表」，即可直接看到全部通知内容（也可临时上滑「更多通知」展开）。

## 本版做的 App 侧改进

1. **锁屏公开可见**：进行中的休息通知改为 `VISIBILITY_PUBLIC`，即使系统开了「锁屏隐藏通知内容」也不会被折叠成「收到一条通知」。
2. **锁屏专用标准布局**：额外提供 `publicVersion`（标准布局：标题「休息中 · 动作」+ 系统 Chronometer 倒计时 + 「共 X 分 Y 秒」），因为自定义 RemoteViews 在锁屏上不一定被渲染；通知栏里仍然是 0.2.14 的大号自定义倒计时。
3. 结束提醒「休息结束，开始下一组」同样设为公开可见。
4. 设置页「后台运行与提醒」新增提示：锁屏只看到「更多通知」时，把系统锁屏通知样式改成「列表」。

## 验证

- Android 14 模拟器（API 34）：锁屏（keyguard）上直接显示「休息中 · …」和系统走秒的倒计时，不需要点「更多通知」；通知栏自定义布局、跳过按钮、息屏走秒、进程被杀后的精确闹钟等 0.2.14 验证项重新跑过。
- 未在澎湃 OS 4 真机复测锁屏样式切换（系统设置项，需用户在手机上确认）。
