# 好奇训练 0.2.13

单机、免注册的健身执行助手：训练日 + 组间休息计时 + 每日热量与三大营养素记录，数据只存本机。

## 这个版本有什么

### 训练

- 自定义循环训练日，可重命名（如「练胸日」）；不绑定日期，任何一天都能直接练。
- 动作可设名称、组数、休息秒数，重量与次数分开设置、分开保存。
- 点组块即完成，自动开始组间休息倒计时；锁屏或切后台时通知栏继续走秒。
- 长按动作卡片可上下拖动调整顺序，带抬起动画，松手即保存。
- 整日「完成」需手动标记，可撤销。

### 饮食

- 按本地日期记录三餐与加餐，跨天自动切换，历史记录保留。
- 活动消耗改为当天在饮食页填写，新的一天从 0 开始。
- 总消耗 = 基础代谢（Mifflin-St Jeor）+ 当天活动消耗；双条同刻度 + 500 kcal 参考虚线。
- 手动录入或编辑食物时，改了名称/份量并点保存，会用 AI 按名称与份量估算一次热量与三大营养素；自己填过数字则直接按你填的保存，不再调用。
- 拍照识别（需自备 API Key）：选图 → 识别 → 逐项确认后才入账。

### 提醒与人性化

- 休息结束震动 + 铃声；划掉通知或按一下电源键立即静音（普通应用无法拦电源键，屏幕仍会照常亮/灭一次）。

## 安装

1. 下载本页下方 `haoqi-training-0.2.13.apk`。
2. 手机允许「安装未知来源应用」后安装。
3. 系统为 Android 8.0（API 26）及以上。

用本机调试证书签名，仅供自己与朋友安装试用，未上架任何应用商店。

## 使用 AI 功能前

在「设置」里填 Base URL（默认 `https://api.deepseek.com`）、模型名（默认 `deepseek-flash`）和自己的 API Key，可点「测试连接」验证。Key 只存在本机 App 私有存储里，仓库和安装包不含任何密钥。识别与估算会产生你自己的 API 费用。

## 已知限制

- 未在物理手机做系统性验证；不同厂商的后台策略、通知栏样式可能影响计时提醒的展示。
- 真实的 AI 图片识别与文字估算未用有效 Key 实测，结果质量取决于所配置的模型。
- 只支持一套循环计划，没有训练历史、多计划、账号同步与趋势统计。
- 未接入小米「超级岛」，使用标准 Android 通知。
- 界面为固定浅色中文，未做多语言。
