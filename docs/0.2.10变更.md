# 0.2.10 饮食页前两张卡片排版

## 问题

饮食页顶部「今日活动消耗」「今日热量」两张卡片里文字挤在一起：标题与说明紧贴、说明与输入框贴边、热量图例和「基础代谢 + 今日活动」几乎连成一行，达标判断与差值两行也粘在一起。

## 改动

**今日活动消耗**

- 标题「今日活动消耗」与说明之间加 6dp 间距；
- 说明文案改为「只记在今天（日期），新的一天从 0 开始」，改用次要色；
- 说明与输入框之间加 16dp；输入框与按钮之间 14dp，按钮固定 48dp 高；
- 校验错误提示、保存结果提示各自留 6/10dp 间距，并统一用次要色（错误仍为红色）。

**今日热量**

- 标题下 10dp，图例（总消耗 / 摄入）改用 `bodyMedium` 并拉开 20dp 列间距；
- 「基础代谢 X + 今日活动 Y」单独一行，8dp 间距、次要色；
- 图表上下留白改为 20dp / 18dp；柱状图本身高度从 88dp 收到 72dp，去掉底部 22dp 空档；
- 虚线图例与达标结论之间 14dp；
- 达标结论与差值拆成两行两级字重：结论 `bodyMedium`（达标为绿色），差值 `bodySmall` 次要色；
- 未配置基础代谢时只显示一行说明，不再显示与「已达到/未达到」冲突的结论。

## 验证

Android 14 模拟器（截图为真实数据：活动 500、摄入 1785、BMR 1648）：

- 两张卡片层次清楚，标题、说明、控件、结论之间都有间距；
- 差额文案仍为「消耗摄入差为：363 千卡（消耗 − 摄入）」，判定为「未达到 500 千卡目标」正确；
- 32 项 JVM 单元测试与 release 构建通过。

## 限制

- 未在物理手机复测；不同字号/字体缩放下间距表现需再看。
- 只调整了饮食页前两张卡片，其余卡片排版未动。
