# 0.2.4 图标改版：右下贴边

- 人物不再居中；按原始剪影的可见边界裁切后，整体贴合图标右下角，右侧与底部各留极小溢出，保证牛仔裤底部与图标底边没有可见空隙。
- 前景高度取 108dp 图层的 0.92，保留头部与顶部遮罩圆角的间隙；使用纯黑背景层，标准、圆形、单色主题图标共用同一前景。
- 版本 versionCode=7 / versionName=0.2.4，无业务与数据库改动。

## 验证

- 生成脚本 `scripts/generate-launcher-icon.py`；前景 432×432，主体 294×397，右侧/底部越界 9px。
- 遮罩预览：`docs/图标预览-右下贴边.png`（方形、圆角方形、圆形三种裁切）。
- Android 14 模拟器覆盖安装后桌面图标已更新为新图案；AOSP 启动器使用方形遮罩，内容填满。
- 注意：若桌面切换成**圆形**图标形状，右下角牛仔裤会被圆形边缘削掉一部分；这是“底边零边距”与圆形遮罩的固有冲突，小米 15 默认圆角方形不受影响。
