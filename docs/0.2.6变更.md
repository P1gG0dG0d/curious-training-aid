# 0.2.6 每日活动消耗

## 需求

饮食摄入按本地日期统计，前一天记录不删除。活动消耗不再作为个人资料里的每天固定值，改由饮食页按当天实际活动填写。

## 预期行为与验收

- 设置仅保留性别、年龄、身高、体重等基础资料。
- 饮食页填写当日活动消耗（千卡），单独按日期保存，重启后可读取。
- 新一天活动消耗默认0，不继承旧设置的300或上一天的输入。
- 消耗由基础代谢与当天活动消耗组成。
- 到午夜日期变化，摄入与活动切到新一天；昨日数据仍保留。
- 数据库升级保留训练、饮食和个人资料，新增每日活动记录表。

## 验证

- 32项JVM单元测试通过（新增非负有限值、跨日编辑保护、旧活动值不参与计算及未配置BMR场景）。
- Python SQLite迁移测试通过：v3旧记录保留，新增表与v4 schema相符，同日更新/不同日隔离。
- Android14模拟器从0.2.5覆盖升级：训练日ChestDay及230 kcal餐食保留；456 kcal活动保存重启仍在；切至新日期摄入/活动为0，恢复原日期显示原始记录。
- 调整模拟器时钟验证前台日期切换，测试结束恢复自动校时；未修改宿主机时钟。
- 真实AI付费识图未测；跨日AI结果使用捕获日期校验，旧日结果不允许误写新日。

旧profile活动列为兼容迁移保留但不参与新计算，数据库v4新增daily_activity(date,kcal)。未配置基础资料时仅显示当天活动的部分消耗并明确提示，不显示达标判断。
