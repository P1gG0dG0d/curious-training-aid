# 好奇训练 · 真机测试清单（v1）

> 目的：以下清单用于物理手机验证，不能用构建成功替代运行验证。
> 2026-10-18 已配置 Android 14 模拟器，完成 0.1.1 启动、主要页面与持久化冒烟测试；详情见 [启动闪退修复.md](启动闪退修复.md)。下面未勾选项不表示已在真机通过。
> 当前修复包：`dist/haoqi-training-0.1.1.apk`；同签名直接覆盖安装，保留数据。

## 安装

```powershell
# USB 连接手机、开启「USB 调试」后：
$env:JAVA_HOME='C:\Users\<用户名>\.jdks\jbr-21.0.11'
.\gradlew.bat :app:assembleDebug
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

首次启动允许「通知」权限（Android 13+ 会弹窗）。

## 1. 训练页

- [ ] 首次打开显示「循环第1天」，没有动作时有引导文案。
- [ ] 「添加一天」后顶部出现「第2天」「第3天」；点「第3天」可直接进入，无需先完成第 1 天。
- [ ] 左右滑动切换训练日，顶部选中态同步。
- [ ] 「添加动作」填：名称、组数 4、休息 90、重量 60、次数 8 → 保存后卡片显示「4 组 · 1分30秒」「重量 60 kg」「次数 8 次」。
- [ ] 编辑动作改重量 62.5 / 次数 10，保存后显示更新；删掉动作后卡片消失。
- [ ] 点第 1 组方块 → 变黑、出现「休息中」横条和通知栏倒计时；再点一次 → 恢复未完成并停止计时（再点取消行为）。
- [ ] 完成 4 组后点右上「完成」→ 显示「循环第1天已练完 ✓」；点「撤销」恢复。
- [ ] 杀掉 App 重开：组块完成状态、整日完成状态、动作重量/次数都还在。
- [ ] 添加 3 天再删除中间一天：剩下的天重新编号为 1..N，动作跟着所属天保留。

## 2. 休息计时（重点）

- [ ] 点完成一组后立即锁屏：通知栏倒计时继续走，到点震动 + 响铃。
- [ ] 切到后台/别的 App 再回来：倒计时没有停、剩余时间和真实时间一致。
- [ ] 点通知里的「跳过休息」：计时立即结束，没有残留通知（或点掉后消失）。
- [ ] 倒计时横条上的「跳过」同样有效。
- [ ] 计时期间再来一组：新倒计时替换旧倒计时，不会两个服务打架。
- [ ] 手机静音/勿扰下：震动是否触发（响铃取决于系统勿扰策略，属预期差异）。

## 3. 饮食页

- [ ] 未填资料时：热量卡提示「先在设置里填个人资料」，灰条为 0，不显示伪造消耗。
- [ ] 设置里填 男/30/175/70/活动 300 → 保存：灰条 = BMR 1649 + 300 ≈ 1949 kcal。
- [ ] 手动录入：早餐「米饭 150g 174kcal 蛋白3.8 碳水38.8 脂肪0.4」→ 蓝条增长、蛋白/碳水/脂肪柱更新。
- [ ] 点食物行展开：显示蛋白质/碳水/脂肪；点铅笔可改份量/热量；点垃圾桶删除。
- [ ] 加餐：没有记录时不显示「加餐」区；加一条后出现。
- [ ] 500 kcal 虚线：消耗 2400 / 摄入 2100 时虚线落在蓝条内部；摄入 1500 时落在蓝条末端之外。
- [ ] 杀掉 App 重开，当天记录还在。
- [ ] 跨过午夜（或改系统时间）回到 App：自动切到新的一天，旧记录不在今天显示。

## 4. AI 拍照识别

- [ ] 设置里填真实 DeepSeek API Key → 点「测试连接」显示「连接成功：deepseek-flash（支持看图）…」。
- [ ] 故意填错 Key → 提示「API Key 无效或无权限」，App 不崩。
- [ ] 断网测试连接 → 提示无法连接/超时，不崩。
- [ ] 拍照识别：允许相机权限 → 拍食物 → 出现「正在识别…」→ 返回结果列表。
- [ ] 结果页可改食物名、份量、热量、蛋白/碳水/脂肪；可删掉误识别的条目；选餐次（早/午/晚/加餐）→「确认入账」。
- [ ] 入账后食物行带「估算」标签，热量/柱状图更新。
- [ ] 相册选图同样可用（Android 13+ 用系统照片选择器，不需要存储权限）。
- [ ] 识别失败（模糊图/非食物）：提示友好，不崩溃。

## 5. 设置与权限

- [ ] 拒绝通知权限：倒计时仍能计时；通知不显示属预期。
- [ ] 设置页左上返回箭头 / 系统返回键都能回到主界面。
- [ ] API Key 输入框默认隐藏，点眼睛可显示。
- [ ] 修改资料保存后，饮食页总消耗立即变化（不用重启）。

## 6. 已知限制（不是 bug）

- 不保存训练历史：只保留当前循环的完成状态和动作参数。
- 一个计划：不支持多套计划并存。
- 固定浅色主题。
- 休息结束响铃用系统闹钟音量；媒体音量调小不一定影响它。
- AI 结果是估算值，不保证准确。
