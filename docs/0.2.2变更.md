# 0.2.2

- App 内“跳过”休息与通知内“跳过休息”现在停止前台服务并取消计时通知，不再将通知留在通知栏。正常倒计时到零仍保留结束提醒。
- API Key 改为普通 ASCII 文本输入，关闭自动纠错，移除密码输入模式和密码遮罩，方便选择/粘贴。输入时 Key 直接可见。
- versionCode=5，可覆盖升级；无数据库变动。

验证：release 构建与模拟器覆盖安装、冷启动通过。实际点组块启动休息，系统存在 id=1001 通知；在 App 点击跳过后，倒计时消失且 dumpsys notification 中无该活动通知。API Key 的 UI 节点 password=false，当前输入法 inputType=0x1（普通文本），非密码类型；未在小米安全键盘上实测。
