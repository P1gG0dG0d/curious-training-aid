# 0.2.0 界面修改

- 选中某个训练日后，再点击顶部按钮打开名称编辑；保存自定义名称，留空恢复第 n 天。切换到其他日仍是单击选择。重命名不影响完成状态。
- 删除“第n天只是计划编号”的常驻提示。
- 热量图移除两条满宽灰色底槽，保留实际消耗/摄入数据条和 500 千卡参考线；横向刻度仍随数据变化，无固定热量容量。
- 差值明确写为“消耗摄入差为：N 千卡（消耗 − 摄入）”，摄入更大时显示负数，避免与距离 500 目标的差值混淆。
- 训练/饮食使用 260ms 平移淡入淡出；设置进入/退出使用 280ms 平移淡入淡出。
- 使用纯白卡片、冷灰背景、近黑按钮和分级灰度图表，移除旅行配色；现有图标背景同步改黑，图标主体留待生成新设计。
- Room v2→v3 只增加 plan_days.name，保留原数据；APK versionCode=3。

## 验证结果

Android 14 模拟器从 0.1.1 覆盖升级：旧训练日与完成状态保留，重命名、重启持久化、再次点选中日打开编辑、取消编辑、饮食/设置往返及明确差值文案均通过。最终 APK 再次安装冷启动通过，无崩溃日志。28 项单元测试通过，release 构建、lint 和签名校验通过。

截图像素统计确认饮食页应用区域为灰度色（无残留彩色像素）。当前模型不支持图像输入，未声称人工目视检查所有布局或动画观感。未做物理手机测试。

## 图片生成能力检查

本机已配置 `paratera / Doubao-Seedream-5.0-lite`。Seedream 5.0 Lite 模型家族具备图像生成能力，但本机这一网关路由尚未实测。当前 DSH 聊天接入的图像输入能力不等于图片输出能力，不能仅切换模型就保证能在聊天中生成图片。未发起付费生成调用。

GLM-4.6V 的已声明能力是图像理解，不应当作图像生成模型。
